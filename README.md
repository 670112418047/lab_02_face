# FaceCheck AI - ระบบเช็คชื่อด้วยใบหน้าอัจฉริยะ (โหมดเดินผ่าน / Walk-by Kiosk)

ระบบเช็คชื่อด้วยใบหน้าอัตโนมัติแบบเรียลไทม์ เหมาะสำหรับการตั้งเครื่องเป็น Kiosk (แท็บเล็ต/มือถือ/คอมพิวเตอร์) ไว้หน้าห้องเรียนหรือทางเข้าสำนักงาน คนเดินผ่านกล้องจะตรวจจับและเช็คชื่อให้ทันทีโดยไม่ต้องหยุดกดปุ่ม

---

## 🌟 ฟีเจอร์เด่นใน Phase 1

1. **โหมดสแกนเดินผ่าน (Walk-by Auto-detect):**
   * ตรวจจับและระบุตัวตนใบหน้าแบบเรียลไทม์อัตโนมัติ
   * วาดกรอบสีเขียวพร้อมชื่อและเวลาเช็คชื่อบนใบหน้าทันที
   * มีตัวกรองระยะใบหน้า (Face Distance Filter) หากอยู่ไกลเกินไปจะยังไม่คำนวณ เพื่อป้องกันภาพเบลอ

2. **ระบบป้องกันการสแกนซ้ำ (Cooldown / Debounce):**
   * เมื่อเช็คชื่อสำเร็จแล้ว ระบบจะล็อคชื่อไว้ (ค่าเริ่มต้น 10 นาที หรือปรับได้ตามต้องการ) ไม่ให้บันทึกซ้ำหลายสิบรอบขณะยืนอยู่หน้ากล้อง

3. **สัญญาณตอบรับทันที (Audio & Visual Feedback):**
   * เสียงสัญญาณ "ติ๊ง" (Web Audio API Synthesizer) โดยไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก
   * ระบบเสียงพูดภาษาไทยสังเคราะห์ (Text-to-Speech): *"เช็คชื่อสำเร็จ คุณ [ชื่อ]"*
   * ป้ายแจ้งเตือน Pop-up Toast ขนาดใหญ่ พร้อมรูป Avatar ของผู้ที่เช็คชื่อ

4. **การบริหารจัดการแบตเตอรี่ & หน้าจอมือถือ:**
   * **Screen Wake Lock API:** ล็อคหน้าจอไม่ให้ดับเองแม้เปิดทิ้งไว้ทั้งวัน
   * **Frame Throttling:** ปรับรอบการประมวลผล AI เป็นทุกๆ 300ms เพื่อถนอมชิปและแบตเตอรี่มือถือ ไม่ให้เครื่องร้อนจัด

5. **ระบบทะเบียนใบหน้า (Face Enrollment):**
   * ถ่ายภาพจากกล้องเว็บแคม หรืออัปโหลดรูปภาพจากเครื่อง
   * สกัด Face Descriptor (เวกเตอร์ 128 มิติ) เก็บไว้ในเครื่องอย่างปลอดภัย
   * มีระบบสำรองข้อมูล (Export Backup JSON) และนำเข้าข้อมูล (Import JSON)

6. **ระบบประวัติและการส่งออกรายงาน (Attendance Report):**
   * สรุปยอดผู้มาเรียน/มาทำงาน: ทั้งหมด, มาตรงเวลา, มาสาย
   * ส่งออกเป็นไฟล์ **Excel / CSV (พร้อม UTF-8 BOM)** เปิดบน Microsoft Excel แล้วภาษาไทยไม่เป็นภาษาต่างดาว

7. **ทำงานแบบออฟไลน์ 100%:**
   * ไฟล์ AI Model และ Library ถูกดาวน์โหลดเก็บไว้ในโฟลเดอร์ `models/` และ `js/` แล้ว จึงสามารถทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต

## 🚀 วิธีเปิดใช้งาน

เนื่องจากเบราว์เซอร์จำเป็นต้องรันผ่านเว็บเซิร์ฟเวอร์เพื่อขอสิทธิ์การใช้กล้อง:

### วิธีที่ 1: รันผ่าน PowerShell Script (มีให้ในโปรเจกต์)
คลิกขวาที่ไฟล์ `server.ps1` แล้วเลือก **Run with PowerShell** หรือพิมพ์คำสั่ง:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
ระบบจะเปิดหน้าเว็บ `http://localhost:8000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Live Server (VS Code / Antigravity)
* เปิดโฟลเดอร์นี้ในโปรแกรม แล้วกด **Go Live** เพื่อเปิดผ่าน Live Server

## 📱 วิธีเปิดใช้งานบนมือถือ (Mobile Device)

เบราว์เซอร์บนมือถือ (iOS Safari และ Android Chrome) มีกฎความปลอดภัยว่า **การเปิดกล้องต้องเป็น HTTPS เท่านั้น** (ยกเว้น localhost)

### เทคนิคการทดสอบบนมือถือ:
1. **ใช้ Cloudflare Tunnel / Ngrok (แนะนำ สะดวกที่สุดและได้ HTTPS ฟรี):**
   ```bash
   # หากมี cloudflared หรือ ngrok
   ngrok http 8000
   ```
   นำลิงก์ `https://xxxx.ngrok-free.app` ที่ได้ไปเปิดบนเบราว์เซอร์มือถือ จะเปิดกล้องได้ทันที
2. **สำหรับ Android Chrome ผ่าน Wi-Fi วงเดียวกัน:**
   * เข้า Chrome บนมือถือ แล้วไปที่ `chrome://flags`
   * ค้นหา `Insecure origins treated as secure`
   * ใส่ IP เครื่องคอมพิวเตอร์ เช่น `http://192.168.1.50:8000` แล้วกด Enable
