# AI Computer Vision Web Applications 🚀

คลังรวมผลงานระบบ Computer Vision & Machine Learning อัจฉริยะแบบเรียลไทม์บนเว็บเบราว์เซอร์ ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ภายนอก

---

## 📌 โครงการที่ 1: FaceCheck AI (ระบบเช็คชื่อด้วยใบหน้า โหมดเดินผ่าน)
🌐 **เข้าใช้งาน:** `http://localhost:8000/index.html`

ระบบเช็คชื่อใบหน้าอัตโนมัติสำหรับตั้งเครื่อง Kiosk หน้าห้องเรียนหรือทางเข้าสำนักงาน
* **เทคโนโลยี:** `@vladmandic/face-api` + TensorFlow.js (ทำงานแบบ Local Offline 100%)
* **ฟีเจอร์เด่น:**
  * สแกนใบหน้าอัตโนมัติแบบเรียลไทม์ พร้อมตัวกรองระยะใบหน้า
  * ระบบ Cooldown ป้องกันการเช็คชื่อซ้ำซ้อน
  * ระบบเสียง "ติ๊ง!" (Web Audio API) และเสียงสังเคราะห์ภาษาไทย (Text-to-Speech)
  * ระบบลงทะเบียนใบหน้าใหม่ และสำรอง/นำเข้าข้อมูล JSON
  * ระบบสรุปสถิติ (ตรงเวลา/สาย) และส่งออกรายงานเป็น Excel/CSV (UTF-8 BOM)
  * หน้าจอล็อคไม่ดับ (Screen Wake Lock) และ Frame Throttling ประหยัดแบตเตอรี่

## 📌 โครงการที่ 2: SignSpeak AI (ระบบตรวจจับและแปลภาษามืออัจฉริยะ)
🌐 **เข้าใช้งาน:** `http://localhost:8000/sign.html`

ระบบแปลภาษามือเป็นข้อความและเสียงพูดภาษาไทยแบบเรียลไทม์ เพื่อช่วยในการสื่อสารของผู้บกพร่องทางการได้ยิน และเป็นสื่อการเรียนรู้ภาษามือแบบ Interactive
* **เทคโนโลยี:** Google MediaPipe Hands (ตรวจจับพิกัดข้อนิ้วมือ 21 จุด 3D) + Geometric Pose Classifier
* **ท่าภาษามือที่รองรับ (9 ท่า):**
  1. ✋ **สวัสดี** (แบมือ 5 นิ้ว)
  2. 🤟 **ฉันรักคุณ / ขอบคุณ** (ชูโป้ง ชี้ ก้อย)
  3. ✌️ **สู้ๆ** (ชู 2 นิ้ว ชี้กับกลาง)
  4. 👍 **ตกลง / ใช่** (ยกนิ้วโป้งขึ้น)
  5. 👎 **ไม่ใช่ / ปฏิเสธ** (คว่ำนิ้วโป้งลง)
  6. 👌 **โอเค / เรียบร้อย** (นิ้วโป้งแตะชี้ กาง 3 นิ้ว)
  7. ☝️ **ขอความช่วยเหลือ / ข้อ 1** (ชี้นิ้วชี้ขึ้น)
  8. ✊ **หยุด / รอสักครู่** (กำมือ)
  9. 🫰 **น่ารัก / มินิฮาร์ท** (จีบนิ้วโป้งกับชี้)
* **ฟีเจอร์เด่น:**
  * **Neon Hand Skeleton:** วาดเส้นโครงกระดูกข้อนิ้วมือเรืองแสงแบบเรียลไทม์ 60 FPS
  * **Hold-to-Confirm Ring:** วงแหวนนับเวลาล็อกท่า 0.75 วิ ป้องกันมือสั่นหรือภาพกระพริบ
  * **Sentence Builder:** กล่องสะสมคำเรียงต่อเป็นประโยค พร้อมปุ่ม *"🔊 อ่านออกเสียงประโยค"*, ลบคำ, และคัดลอก
  * **Practice Quiz Mode:** โหมดเกมฝึกทำท่าตามที่ AI สุ่มโจทย์ พร้อมระบบนับคะแนนและสตรีค
  * **Gesture Cheat Sheet:** การ์ดแนะนำท่าทางด้านข้าง พร้อมไฟนีออนสว่างตามท่าที่ทำอยู่

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกที่ไฟล์ `server.ps1` หรือเปิดเทอร์มินัลแล้วพิมพ์คำสั่ง:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
2. เลือกระบบที่ต้องการเปิดบนเบราว์เซอร์:
   * **ระบบเช็คชื่อใบหน้า:** `http://localhost:8000/index.html`
   * **ระบบแปลภาษามือ:** `http://localhost:8000/sign.html`

## 📱 วิธีเปิดใช้งานบนสมาร์ตโฟน (Mobile Device)

เบราว์เซอร์มือถือต้องรันผ่าน HTTPS เพื่อเปิดกล้อง:
1. **ใช้ Ngrok หรือ Cloudflare Tunnel (สะดวกที่สุด):**
   ```bash
   ngrok http 8000
   ```
   นำ URL HTTPS ที่ได้ไปเปิดใน Safari (iOS) หรือ Chrome (Android) จะเปิดกล้องได้ทันที
2. รองรับการกดปุ่ม **"🔄 สลับกล้อง"** เพื่อสลับระหว่างกล้องหน้าและกล้องหลังได้
